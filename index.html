다양한 미니 게임과 인터랙티브 경험을 한곳에 모은 웹 앱 컬렉션! 간단한 숫자 게임부터 MBTI 테스트까지, 누구나 쉽게 즐길 수 있습니다.

📊 갓생 플랫폼 소개

갓생은 가벼운 게임과 테스트를 통해 짧은 시간에 재미와 몰입을 제공하는 웹 앱 모음입니다. 친구들과 점수를 겨루거나, 혼자 집중해 기록을 세워보세요. 아래에서 제공되는 앱을 클릭하면 즉시 해당 서비스로 이동합니다.

🎮 제공 기능

  • Number Game — 직관적인 숫자 추측 게임으로 반사 신경과 운을 시험해보세요.
  • Simple Quiz Game — 다양한 주제의 객관식 퀴즈로 지식을 확인하세요.
  • Gomoku & Bingo — 고전 오목과 빙고를 혼합한 캐주얼 게임.
  • MBTI Game — 간단한 질문으로 성격 유형을 알아보는 테스트.

각 앱 페이지에는 간단한 설명과 실행 버튼이 있으며, 실제 앱은 Streamlit으로 배포되어 있습니다. '실행하기' 버튼을 누르면 해당 Streamlit 앱으로 이동합니다.
